# Turn risks into checks

Read the actual brief/plan and its evidence. For native handoff read
[the shared contract](../adhd-native/references/skill-handoff.md).

Imagine a concrete failed outcome and identify which assumption caused it. Label
this as a scenario, not an observed incident. Include execution feasibility as
well as user value. Inspect the evidence already available before proposing work.

For each material assumption record: current evidence and what is missing;
impact if false; smallest discriminating check; success/failure/uncertain outcome;
and the decision each result would change. Prefer observed behavior over a poll
of opinions when evaluating actual adoption or usage.

Prioritize by consequence and evidence weakness with explicit reasoning. Do not
invent probabilities, numeric confidence or a fixed quota of criticisms. Start
with the most consequential unknown; ordinary low-risk details need no workshop.
If an authorized small check is feasible, give it to the current owner to run.
Report the result only after observing it. Otherwise return a proposed check.

Finish when the owner can distinguish prerequisites from risks to monitor while
proceeding. Return risk/check/decision records and the next action. A failed check
can justify revising the approach; it cannot silently remove user requirements.
Route a necessary requirement change to steer. The eventual candidate still needs
the existing independent verification.

Example: for “날짜별 연구 기록 정리 계획의 허점 봐줘”, examine the assumption that file timestamps
equal experiment dates and propose a real conflicting-record check.

## Method inputs

Combine [Klein's premortem](https://www.gary-klein.com/premortem),
[assumption prioritization and behavioral tests](https://github.com/phuryn/pm-skills/blob/8607e3b077817f89bf4a9b623246219734ac3be0/pm-product-discovery/skills/prioritize-assumptions/SKILL.md)
and [NASA's uncertainty-aware decision analysis](https://ntrs.nasa.gov/api/citations/20080008301/downloads/20080008301.pdf).
The adaptation does not establish effectiveness in ADHD or validate an assumption.
