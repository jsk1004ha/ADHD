# Reports / abstracts / presentation artifacts
First read the actual rubric/template and the actual research source files. Convert format constraints into checkable items: language, sections, page count, columns, fonts, type sizes, figure/table labels, abstract/title limits, citation style and required content. If no template exists, choose a restrained format without inventing submission requirements.

Reuse installed documents/pdf/spreadsheets/presentations plugins or the corresponding local docx/pdf/pptx skills. Never recreate fonts or export engines casually. When a plugin is unavailable to the CLI, select a genuinely installed local tool or state the blocker; do not pretend a cache entry is a working tool.

Draft only claims supported by the given data and sources. Distinguish simulations, predictions and measurements. Keep an internal claim→source/result ledger. Recompute copied numerical summaries. Preserve equations, units and uncertainty. Do not exaggerate statistical conclusions or hide weaker comparisons.

Render the final artifact using available local tooling and inspect EVERY page/slide, including captions and tables, at a readable scale. Save preview images and validation output inside the workspace where feasible. Check page/word/line constraints and overflow, corrupted glyphs, image cropping and legibility. For spreadsheets check formulas and calculated values, not just appearance. The independent reviewer must inspect the actual final output or its faithfully rendered previews; inability to inspect is a limitation, not “verified”.
