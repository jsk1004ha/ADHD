# ADHD 0.1.7 — 2026-10-18

필요한 문맥만 전달하고, 중복 저장과 작업 대기를 줄이는 경로를 추가합니다.
기존 인증·선택 모델·effort·라우터·플러그인과 검증·복구 관문을 유지합니다.

## 문맥과 저장공간

파일·심볼 탐색과 문맥 전달은 범위와 출력량을 제한하고, 원문 대신 검증 가능한
참조를 재사용합니다. 중앙 문맥 저장소는 파일 변경과 출처를 확인하며, 다른 프로젝트나
권한 범위의 자료를 섞지 않습니다. 공유 불변 소스와 내용 기반 저장으로 중복을 줄이고
명시적인 보존·정리 정책을 사용합니다. 활성 작업과 재개 자료는 자동 삭제하지 않습니다.
스레드·역할·출력·저장공간 예산을 함께 다루며, 토큰 관측이 없으면 비용을 추정해
측정값처럼 보고하지 않습니다.

## 작업 시간과 빠른 피드백

native begin의 선택 옵션 `--time-limit-seconds 900 --review-reserve-seconds 180`은
작업에 15분을 배정하고 그중 3분을 검사와 독립 검토에 남기는 예입니다. 기본 작업에
새로운 시간 제한을 강제하지 않습니다. 재개 시 시작 시각을 바꿔 한도를 초기화하지 않으며,
시간 만료는 완료 승인이 아닙니다. 실행 중인 자식을 정리하고 미완료 범위를 기록합니다.
후크는 다음 경계에서 제한을 적용하므로 진행 중인 호스트·모델 호출을 즉시 중단할 수는
없습니다.

batch는 공유 마감 시각과 선택적인 `shortest_first`·`fail_fast`를 지원합니다.
짧은 검사를 먼저 실행하고 실패를 빨리 확인할 수 있지만, 생략되거나 시간 초과한
필수 검사를 통과로 처리하지 않습니다. 소유한 CLI 프로세스에는 실행 예산을 적용합니다.

## 배포와 검증 범위

현재 공개 자료의 개인 PC 경로를 예제 경로로 정리했습니다. 개인 계획·실행 로그·
계정 인증·설정은 공개 패키지에 포함하지 않습니다. 기존 공개 Git 이력을 다시 쓰지는
않습니다. Windows 설치 파일에는 공식 Python 3.13.16 런타임이 포함됩니다.
기존 설치는 `python adhd.py upgrade` 또는 검증된 Windows 설치 파일로 갱신합니다.
Codex를 재시작해야 새 후크·역할을 로드하며, 열린 세션의 캐시가 갱신되었다고 간주하지
않습니다. native 상태 스키마는 2를 유지합니다.

기능·회귀·패키지 검사를 실과업의 전체 속도 향상과 구분합니다. 앞선 36건 비교 평가는
전체 시간·토큰 절감의 채택 기준을 충족하지 못했습니다. 이번 기능으로 모든 작업이
더 빨라졌다는 주장이나 실측하지 않은 메모리·디스크 절감률은 제공하지 않습니다.
