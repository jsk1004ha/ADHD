# 0.3.1 — success, reuse and failure learning

Completed tasks report success and automatically retain a project-scoped recipe
and discoverable SKILL.md. Checked auto completion and independent review use the
same learning path. Missing manual procedure steps fall back to actual artifacts,
requirements and check references; replayed completion events are idempotent.

Observed tool and check failures are saved from the first attempt. Recovery and
later task completion are attached without erasing the original failure, and the
next run recalls a small project-local reminder. Storage problems are reported
separately and do not undo a completed task. No extra model call is needed.
