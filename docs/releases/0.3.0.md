# 0.3.0 — outcome-first defaults

Auto now prioritizes the requested result with proportionate checks. Mandatory
independent review remains available through strict profiles or candidate opt-in.
Repeated approvals are idempotent, failure/pending tool responses stay honest, and
feedback reuses only verified evidence for unchanged requirements. Startup skills
are shorter and bounded tasks can run directly. Existing active runs keep their
profile. See [workflow details](../outcome-first.md).
