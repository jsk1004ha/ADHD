# ADHD 0.2.1

Diagnostic generators can run directly with `workspace-storage run --argv ...`
without retaining a separate command payload file. Direct runs default to their
registered scratch cwd, relocate producer OS temporary paths, and accept explicit
`{scratch}`/`{results}` path arguments. Existing JSON requests keep their cwd
behavior. Originals and required evidence stay outside disposable scratch.

Producer success, failure and timeout retain an explicit cleanup receipt. Native
terminal hooks queue registered leftovers after children stop, using a bounded
metadata query and short lock waits. The next owned command recovers them outside
the hook. Active/unknown producers, references, links and
unregistered directories remain protected. The update does not change host
approval rules or retry previously denied cleanup targets.

Failed Windows process launches now close their owned launcher pipes as well as
their temporary launch specification. A missing tool retains a failure report
without a spurious missing-log cleanup warning.
