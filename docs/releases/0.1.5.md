# ADHD 0.1.5 — 2026-10-05

소스 목록 검사 최적화와 오래된 관리 릴리스의 저장공간 정리를 추가합니다.
기존 대규모 실행, 작업 계약, 독립 검토, 설치·복구 기능은 유지합니다.

## 소스 목록 검사

`coding_scope._tree`의 한 번의 탐색에서 루트의 실제 경로를 재사용합니다.
각 항목의 상위 링크·정션과 실제 경로·폴더 내부 포함 여부는 매번 확인합니다.
정렬·제외 규칙·2만 개 제한·내용 변경 검사와 기존 CLI 동작을 유지합니다.
호출 사이의 mtime·내용 캐시는 추가하지 않습니다.

변경 전후를 같은 입력에서 번갈아 측정하는
`scripts/benchmark_scope_inventory.py`와 경계·실패 회귀 검사를 제공합니다.
기준 소스는 최적화 전 commit `69d39af32ef3`의 `adhd/coding_scope.py`입니다.
측정 범위는 파일 목록 검사이며, 전체 작업 시간이나 토큰 절감 수치를 의미하지 않습니다.

## 명시적 저장공간 정리

체크아웃 또는 설치된 릴리스 폴더에서 다음 명령을 실행합니다.

```console
python -m adhd.storage scan
python -m adhd.storage prune
python -m adhd.storage prune --apply
```

`scan`과 `--apply` 없는 `prune`은 읽기 전용 미리보기입니다. 별도 Codex
설치는 `--codex-home PATH`로 지정합니다. `--keep-releases N`은 현재
릴리스를 포함해 최소 2개이며, 기본값 2는 현재 버전과 최근 복구용 버전을
남깁니다. 참조된 버전은 이 개수에 추가로 보호합니다.

- 현재 설치, 현재 실행 코드와 이전 채팅의 native state 참조를 보호합니다.
  완료된 작업의 state도 아직 열린 채팅과 구분할 수 없으므로 보호합니다.
- 설정·후크·관리 파일·사용자 역할과 스킬의 알려진 참조를 확인합니다.
- 기존 설치·제거 기록의 정확한 manifest로 소유권·내용을 확인합니다.
  알 수 없는 폴더, 수정된 파일, 새 파일·빈 폴더, 링크·정션·reparse point를 정리하지 않습니다.
- 설치 잠금을 잡고 계획 후 참조와 바이트를 다시 검사합니다. 한 릴리스를
  같은 관리 폴더의 임시 경로로 옮긴 뒤 다시 검사하고 삭제합니다. 삭제 전
  검사 실패 시 원래 경로로 돌립니다. 임의의 외부 동시 쓰기에 대한 원자성
  보장은 추가하지 않습니다. 삭제 도중 I/O 오류가 나면 남은 폴더를 보존합니다.
- 인증, 모델·effort, 라우터, 플러그인, 사용자 스킬, 백업, 대화·작업 기록,
  별도 builtin 릴리스와 사용자 프로젝트 데이터는 삭제 대상이 아닙니다.

출력의 `reclaimable_bytes`와 `reclaimed_bytes`는 검증한 파일의 논리적
바이트 합입니다. 파일시스템 실제 할당량이나 전체 디스크 여유 공간으로
해석하지 않습니다. 정리된 오래된 릴리스는 재설치해야 다시 사용할 수 있습니다.

## 업그레이드

기존과 같이 `python adhd.py upgrade` 또는 플랫폼 설치 스크립트를 사용합니다.
저장공간 정리는 업그레이드와 별도로 명시적으로 요청할 때만 실행합니다.
기존 설정·인증·사용자 정의와 native state를 보존하며, 역할 모델의 강제
이전이나 스킬/플러그인 재설치를 추가하지 않습니다.

열린 Codex 채팅은 로드한 릴리스와 역할 정보를 캐시할 수 있습니다.
업그레이드 후 새 채팅에서 0.1.5를 로드합니다. 설치 파일 교체만으로 현재
채팅의 실행 버전이 바뀌었다고 판단하지 않습니다.
