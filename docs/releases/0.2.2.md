# ADHD 0.2.2

Explicit goal skill links can follow the task as a trailing invocation clause
after a comma, semicolon or newline, including selections beside other skills.
The original prompt and other skill selections remain intact. Explanations,
quoted examples and Markdown code do not become persistence commands.

Supported `begin` and `goal` operations can recover an invocation missed by an
older parser from the last recorded user prompt. Source-turn binding, pending
intent reconciliation, explicit limits and independent acceptance still apply.
This does not enable an existing task's goal mode merely by upgrading files.
