# 0.3.2 — continue to the requested outcome

Ordinary auto tasks no longer end at implicit round, elapsed-time or stagnation
limits. Explicit limits and stop requests remain binding. Method-level failures
retain their failure record and retry restriction while allowing other authorized
work. Known remaining work survives compaction and prevents premature completion
and skill promotion. The default guidance follows the original request through
implementation, integration, delivery and the requested use flow.
